# VisionFlix Avatars

Biblioteca de avatares do aplicativo VisionFlix.

## Categorias

As categorias e seus identificadores estão em [`categories.json`](./categories.json).

## Organização das imagens

- Uma imagem por personagem, nunca colagens.
- Preferir imagens quadradas, com rosto centralizado e boa resolução.
- Nomes de arquivo simples, em minúsculas e separados por hífen.
- Manter os arquivos organizados na pasta da respectiva categoria.
- Usar somente imagens próprias, licenciadas ou com autorização de uso. Encontrar uma imagem na internet ou hospedá-la no GitHub não concede direitos de redistribuição.

## Integração no VisionFlix

O catálogo `categories.json` será usado como referência para integrar a galeria ao aplicativo e armazenar a identificação/URL do avatar selecionado no Supabase.
