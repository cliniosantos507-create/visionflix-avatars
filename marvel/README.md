# Marvel - MCU

Primeira seleção com 41 entradas individuais de personagens e intérpretes do Universo Cinematográfico Marvel.

- Catálogo: [`characters.json`](./characters.json)
- Proporção recomendada: 1:1
- Resolução recomendada: 512 × 512 px
- Um personagem por arquivo, sem montagens ou colagens.

## Estado das imagens

Os registros foram preparados, mas os campos de imagem permanecem vazios até encontrarmos arquivos com licença ou autorização compatível com a publicação e distribuição do VisionFlix. Fotografias promocionais, capturas de filmes e imagens encontradas em buscadores não são automaticamente livres para redistribuição.

## Nomenclatura sugerida

`iron-man.webp`, `captain-america.webp`, `thor.webp`, etc.
